# SahaayaLearn Curricular Data Sources & Licensing

## Overview
SahaayaLearn prioritizes curriculum grounding while respecting copyright law and open education licensing terms.

---

## 1. NCERT Official Curricula
- **Status:** Curricular Reference Standard
- **Usage Policy:** In compliance with NCERT published copyright guidelines, raw NCERT textbook PDFs are not redistributed or packaged within the software binary. NCERT chapter titles, learning objectives, and curriculum sequencing serve as the verified reference ontology for syllabus alignment.

---

## 2. SahaayaLearn Original Curricular Seed Corpus
- **Directory:** `server/data/seed/lessons/`
- **License:** Creative Commons Attribution-NonCommercial 4.0 International (CC BY-NC 4.0)
- **Author:** SahaayaLearn Academic Team
- **Subjects:**
  - Mathematics: Fractions, Integers, Decimals, Ratios
  - Science: Photosynthesis, Motion, Friction, Energy
- **Coverage:** Classes 6–8 (NCERT and Karnataka State Board aligned)
